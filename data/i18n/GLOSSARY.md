## คำกริยา/คำทั่วไป แปลแบบนี้เสมอ
Boost = เพิ่มพลัง · Damage = ทำดาเมจ · Destroy = ทำลาย · Strengthen = เพิ่มพลังพื้นฐาน · Weaken = ลดพลังพื้นฐาน · Reset = รีเซ็ต · Move = ย้าย · Play = เล่น · Create = สร้าง (ให้เลือก) · Draw = จั่ว · Discard = ทิ้ง · Return = คืน · Shuffle = สับ · Transform = แปลงร่างเป็น · Copy = คัดลอก · Toggle = สลับ
unit = ยูนิต · allied = ฝ่ายเรา · enemy = ศัตรู · row = แถว · round = รอบ · turn = เทิร์น · hand = มือ · deck = เดค · graveyard = สุสาน · board/battlefield = สนาม · power = พลัง · base power = พลังพื้นฐาน · provision(s) = provision · Bronze/Gold = Bronze/Gold · opponent = คู่แข่ง · adjacent = ข้างเคียง · random = สุ่ม · highest/lowest = สูงสุด/ต่ำสุด · self = ตัวเอง
- โครงประโยค: "Deploy: Damage 3 enemy units by 1." → "Deploy: ทำดาเมจ 1 แก่ยูนิตศัตรู 3 ตัว"
- flavor text แปลให้เป็นภาษาไทยธรรมชาติ รักษาอารมณ์ประโยค (ไม่ต้องตรงตัว)
